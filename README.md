# GenLayer Spinner – Neural Consensus

Animated loading spinner designed for the GenLayer Portal.

## Concept
8 validator nodes arranged in a circle. A soft pulse travels from node to node, representing AI validators reaching consensus — one agreement at a time.

## Features
- Pure HTML + CSS (no JavaScript)
- Uses official GenLayer brand colors (`#110FFF`)
- Center mark stays static (follows brand guidelines)
- Lightweight & smooth (1.6s loop)
- Supports `prefers-reduced-motion`
- Works on light & dark backgrounds

## Preview
Open `index.html` in your browser to see the animation.

Created for the **Design the GenLayer Spinner** mission on the GenLayer Portal.
